# Archived experiments

These are earlier prototypes kept for reference. The supported, current workflow is documented in the repository root README and uses `train_torch.py`, `generate_torch.py`, and `philosophy_torch.pt`.

- `character_demo/`: standard-library character model, toy corpus, and Wikipedia dump extractor.
- `synthetic_demo/`: model trained on a generated short story.
- `single_book_experiments/`: earlier character, tinygrad, and PyTorch trials using only *Meditations*. The source corpus is excluded from the repository; obtain the text separately if retraining.
